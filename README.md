🖥️ CMD-Style PortfolioAn interactive, command-line interface (CLI) inspired personal portfolio website. Designed for developers and tech enthusiasts, this portfolio offers visitors a unique terminal experience to explore skills, projects, background, and contact details using simple commands.🌟 FeaturesInteractive Terminal UI: Mimics a real command-line interface with customizable theme presets or classic retro styling.Custom Command Parser: Execute commands like help, about, skills, projects, clear, and contact.Responsive & Lightweight: Built for smooth performance on both desktop and mobile devices.Auto-Suggestions & History: Supports command navigation using keyboard arrows (Up / Down for history) and auto-completion (Tab).Clean Structure: Modular codebase making it easy to customize and deploy your own data.🛠️ Built WithHTML5 - Page structure & Semantic layoutCSS3 - Custom terminal styling & AnimationsJavaScript (ES6+) - Command parsing logic, state management, and DOM manipulation🚀 Quick StartFollow these steps to run the project locally on your machine.PrerequisitesYou only need a modern web browser installed (e.g., Chrome, Firefox, Edge, Safari).InstallationClone the repository:git clone https://github.com/Tawhid-01/portfolio--cmd-.git
Navigate into the project directory:cd portfolio--cmd-
Open the project:
Simply double-click index.html or open it using your web browser.Alternatively, if using VS Code, right-click index.html and select Open with Live Server.💻 Supported CommandsCommandDescriptionhelpLists all available commandsaboutDisplays personal bio and summaryskillsDisplays technical skills and programming languagesprojectsDisplays featured projects with linkscontactShows social media handles and email addressclearClears the terminal screensudoSecret command / Easter egg⚙️ CustomizationTo personalize this portfolio with your own information:Modify Personal Details: Open script.js (or the main JS file) and update the JSON object or variables holding user information (e.g., about, skills, projects, socials).Adjust Styling: Customize fonts, colors, and prompt styles in style.css.Add Commands: Extend the switch case / command handler function in JavaScript to add custom commands.🌐 DeploymentYou can deploy this site effortlessly using GitHub Pages:Go to your repository settings on GitHub.Navigate to Pages (under Code and automation).Under Build and deployment > Source, select Deploy from a branch.Choose main (or master) branch and /root folder, then click Save.📄 LicenseThis project is open-source and available under the MIT License.
